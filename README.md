# Tienda Alfajor

Fork single-tenant de la tienda pública. No asumir paridad con `web/`: este proyecto contiene personalizaciones propias y trabajo de catálogo de indumentaria.

Para flujos compartidos, consultar [`../AGENTS.md`](../AGENTS.md); para una tarea local, empezar por `src/main.tsx` y seguir sólo los imports de este clon.

```bash
bun install
bun run dev
bun run build
bun run lint
```
